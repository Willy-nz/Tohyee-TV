GET CONNECTED

Your channel, step by step.

1. Add the Chrome extension

Open Chrome and enter chrome://extensions. Enable Developer mode, select Load unpacked, and choose the folder opened below.

Pin Tohyee TV in Chrome. Open your video tab, click the Spitz icon and choose the channel and then Broadcast this tab to Plex. Chrome requires that click each time capture is started.

2. Where is your Plex server?

Leave this off if Plex runs on this PC. Turning it on restarts the tuner and allows local-network access. Allow Tohyee TV through Windows Firewall on Private networks only. No router changes are needed.

Tuner address
Programme guide

3. Connect in Plex

Open Plex → Settings → select your server → Live TV & DVR → DVR Setup. Manually enter the tuner address if it is not found. Choose the Tohyee TV channel and supply the XMLTV guide address above, then map the channel.

Already have a DVR? Changing to an XMLTV guide can require recreating the DVR. Check Plex’s instructions and your existing recording setup before making changes.

You need permission to manage the Plex server. Account features and exact screen labels vary with Plex version.

4. Check picture and sound

Play Tohyee TV in Plex. The app should show LIVE and a connection count. Confirm you can see moving video and hear sound. Connection status alone does not confirm playback.

Changing source stops any current broadcast. The test picture includes a tone and isolates Plex setup from Chrome capture.

YOUR LINEUP

Make room for more.

Add up to 200 channels. Give each a unique number and name. Use reusable tabs to play any saved channel with a small number of Chrome tabs. Enter each channel’s actual video page address below. Dedicated mode keeps the previous one-tab-per-channel behaviour.

In reusable mode, open three Sky Go tabs, sign in, and arm them as Reusable tab 1, 2 and 3 in the extension. Keep those tabs open. Selecting a channel in Plex navigates an available tab to its saved page. When all tabs are busy, another different channel is refused. Changes stop current broadcasts.

Sky Go channels

Fill in all of Sky Go’s live channels: Sky’s channel numbers and names, their Sky Go page addresses, and their programme guide matches. Channels you already have, by number or address, are left as they are. Remove any you don’t want, then click Save channels.

Use Reusable tabs with a list this long, so only a few Sky Go tabs are open at once. Sky Go only lets a few devices watch at the same time.

Sky programme guide

Listings refresh every six hours. Cached listings are kept if a download fails. Select a guide match for each channel; unmapped channels keep placeholder listings.

This adds names and guide mappings. Paste the corresponding Sky Go live-channel page links before tuning them. Remove channels you do not need.

Saving stops all broadcasts. Start each tab again afterwards. In Plex, rescan the tuner’s channels, refresh the XMLTV guide and map the new channels. Channel numbers are their identities; keep existing numbers to preserve mappings.

Only watched channels send media to Plex, but a website may still count a paused player as watching. Service playback limits still apply. Stop or exit unused players when necessary. Mapped channels show the downloaded programme schedule.

MAKE IT YOURS

Simple defaults.

Windows startup

Starts quietly in the tray. Chrome still needs you to select a tab and start broadcasting. Capture stops when Windows locks or sleeps.

Start broadcasting by itself

Tohyee TV uses its own Chrome window, separate from your usual Chrome, so it can start your channels without a click after a restart or after Windows is unlocked. Each channel needs its video page address (Channels).

Set up once: click Set up Chrome window, then follow the steps on the page it opens: add the extension, sign in to your video website, and click Arm this tab for Plex once on that site. Turn on Start Tohyee TV when I sign in to Windows above as well. Windows must sign in by itself after a restart, and broadcasting stops while Windows is locked.

Video processing

Automatic avoids a second video encode when Chrome supplies H.264. Audio is converted to AAC for Plex. Other video formats use the bundled encoder.

If passthrough fails before video starts, the next tune uses compatibility encoding. If your TV plays poorly, select Compatibility and tune again. Changing this setting stops the current stream.

Updates

Tohyee TV checks GitHub when it starts and once a day, and tells you when there’s a new version. It only reads the public list of releases; nothing about you or your broadcasts is sent. It never installs anything by itself: when there’s a new version, click Update now. Tohyee TV downloads it from GitHub, checks it against the release’s checksum, then closes, updates and opens again. Any broadcasts stop, so click Broadcast again in each Chrome tab afterwards.

Bundled software

FFmpeg and its software encoder are installed with the app. No extra download is needed.

HELP & DIAGNOSTICS

See what’s happening.

Common fixes

Port already in use: close the old command-window tuner, then Restart tuner.

Chrome says it cannot connect: use tuner port 34500 in the extension unless you changed the app configuration.

No picture or sound: try the built-in test picture first, then a normal unprotected video in Chrome. Captured protected content may be unavailable.

Network Plex cannot connect: enable network access in setup, use this PC’s LAN address, and check its Private-network firewall permission.
