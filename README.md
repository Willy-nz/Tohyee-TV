# Tohyee-TV
A Windows desktop app that turns your computer’s screen and audio into a live TV channel in Plex, using FFmpeg streaming and HDHomeRun-compatible tuner emulation. No physical TV tuner required.

## First prototype

Start with the [Firefox capture check](firefox-prototype/README.md) to test local picture and audio compatibility. This is a window/screen preview, not yet a Plex broadcaster or Windows installer.

See the [development plan](docs/DEVELOPMENT_PLAN.md) for the full application roadmap.
